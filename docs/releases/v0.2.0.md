# SEEK Auto v0.2.0 — 第二版

發布日期：2026-11-24（Australia/Sydney）

前一版本：v0.1.0

適用專案：[Williamlaiwei/seek-auto](https://github.com/Williamlaiwei/seek-auto)

第二版改善首頁搜尋入口，並補齊版本辨識、更新紀錄、安裝與升級說明。這次以介面與交付文件更新為主；職缺分析與 Cover Letter 使用第一版既有的本機程式與 AI 連線流程。

## 這次更新了什麼

| 項目 | v0.1.0 第一版 | v0.2.0 第二版 |
| --- | --- | --- |
| 首頁搜尋區 | 需要先按搜尋切換按鈕展開 | 預設展開，直接顯示關鍵字、地點與搜尋按鈕 |
| 搜尋區無障礙狀態 | 初始 `aria-expanded="false"` | 初始 `aria-expanded="true"`，對應顯示狀態 |
| 版本辨識 | 發布 ZIP 中有 VERSION | 原始碼加入 VERSION，首頁與 README 也標示版本 |
| 更新說明 | README 與 CI/CD 指南 | 另有完整 CHANGELOG 與第二版專屬說明 |
| 下載文件 | ZIP 內有 README 與授權 | 另附更新紀錄、第二版說明、CI/CD 指南及 .gitignore |
| GitHub Release 內容 | 自動產生的提交紀錄 | 優先採用此 Markdown 檔作為詳細發布說明 |
| 本機資料 | SQLite 儲存 | 格式沿用，沒有資料庫結構變更 |

搜尋區仍可以收合；直接貼 SEEK 網址、手動新增職缺與搜尋三種入口都可繼續使用。預設展開只改變畫面顯示，載入首頁不會自動搜尋，也不會自動呼叫 AI。

## 下載與啟動

1. 前往 [v0.2.0 Release](https://github.com/Williamlaiwei/seek-auto/releases/tag/v0.2.0)。
2. 下載 `seek-auto-v0.2.0.zip`；同頁的 `seek-auto-v0.2.0.zip.sha256` 可用來核對檔案。
3. 完整解壓縮，進入 `seek-auto-v0.2.0` 資料夾。
4. 安裝 Python 3.10 或以上版本，並確認命令列能執行 `python`。
5. Windows 可雙擊 `start-web.cmd`；其他系統或命令列執行：

```sh
python server.py
```

程式會開啟 `http://127.0.0.1:8766`。保留啟動視窗，按 Ctrl+C 停止。若連接埠被占用，可改用 `python server.py --port 8767`；不需自動開瀏覽器時使用 `python server.py --no-browser`。

執行應用程式不需要 Node.js、不需要安裝第三方 Python 套件，也不需要建置前端。使用雲端 AI 需要另外準備相容服務的 API 設定與可用額度。

使用 Git 取得指定版本：

```sh
git clone --branch v0.2.0 --depth 1 https://github.com/Williamlaiwei/seek-auto.git
cd seek-auto
python server.py
```

## 完整使用流程

### 1. 設定個人背景與 AI

- 開啟右上角 **My profile & API**，貼上工作經歷、技能、具體案例與求職偏好。
- 可以匯入 `.txt`、`.md`、`.json` 文字檔，並加入過去 Cover Letter 作為語氣及結構參考。
- 選擇服務商，填入帳戶可用的模型 ID 與 API Key，按 **Test connection** 檢查連線。
- 相容服務必須支援 Chat Completions 與 JSON mode；本機相容端點可以使用 localhost HTTP，遠端端點需 HTTPS。
- API Key 僅留在目前頁面記憶體，重新整理或關閉後需要重填。其他偏好會保存在本機。

### 2. 加入職缺

- **網址匯入**：貼上 SEEK 職缺網址，再按 **Add this job**。
- **搜尋**：第二版首頁已顯示搜尋欄位，輸入職稱或關鍵字、選擇地點，再按 **Search jobs**。
- **手動新增**：按 **Paste a description instead**，填入工作描述；當網站匯入失效時仍可繼續使用。

### 3. 分析與生成 Cover Letter

- 選擇職缺，生成英文 Cover Letter，並查看適合度、優勢、落差與待確認事項。
- 個人背景提供事實依據；範例信件提供寫法參考。送出前請核對生成內容是否符合自己的實際經歷。
- 在編輯區直接修改，草稿會自動保存；可輸入具體要求進行重寫，並保留最多五份先前版本。
- 已有信件可再次開啟。對相同輸入的快取命中不會重複發出生成請求；重新生成或修改輸入可能再次呼叫 AI。

### 4. 複製、投遞與追蹤

- 複製信件，再按 **Apply on SEEK** 開啟職缺。
- 在 SEEK 或雇主網站完成申請，之後自行把本機狀態改為 **Applied**。
- 開啟連結、生成或複製信件均不會自動提交申請。
- 可依條件篩選與匯出職缺；匯出內容包含信件及歷史版本，可能含有你在信件中提供的個人資料。

## 從 v0.1.0 升級

### 使用 ZIP 的情況

1. 停止舊程式，關閉啟動它的伺服器；避免複製仍在寫入的資料庫。
2. 備份舊版整個 `.local/` 資料夾，另存一份備份。
3. 將新版解壓到獨立目錄，確認是 `v0.2.0`。
4. 在新版尚未啟動前，把舊版 `.local/` 複製到新版根目錄。若新版已啟動過，先停止並備份新版自己的資料，再決定使用哪份資料。
5. 啟動新版，確認職缺、草稿與偏好都能讀取，重新輸入 API Key。

`.local/` 是隱藏資料夾；檔案總管找不到時，請開啟顯示隱藏項目。單獨匯出的職缺 JSON 不包含完整個人背景與設定，完整移轉請備份 `.local/`。

### 使用 Git 的情況

先停止程式並備份 `.local/`。確認 `git status` 沒有需要保留的程式碼修改，再更新：

```sh
git switch main
git pull --ff-only origin main
python server.py
```

`main` 可能包含後續開發變更；需要固定使用本次版本時，使用 `git fetch origin --tags` 再執行 `git switch --detach v0.2.0`。不要用強制重設覆蓋自己的修改。

本次沒有資料庫遷移指令，也不會自動搬移或刪除舊版資料。確認新版可正常使用後，再自行決定是否保留舊版目錄。

## 回復到第一版

停止第二版，從獨立資料夾啟動保留的第一版。若需要還原資料，使用升級前備份的 `.local/`。回復備份會回到備份當時的狀態，不包含後來新增的草稿或職缺，請先保存第二版資料。

## 發布內容與驗證

- 發布檔：`seek-auto-v0.2.0.zip` 與對應 `.sha256` 檔案。
- ZIP 內的 `VERSION` 標示版本，`MANIFEST.json` 記錄各檔案的 SHA-256。
- ZIP 採明確檔案白名單打包；不包含使用者 `.local/`、履歷、API Key、瀏覽器狀態或個人資料庫。
- 版本標籤會觸發 Windows／Linux 後端、瀏覽器及解壓後啟動檢查；各項必要檢查通過後才發布 Release。
- 自動測試使用合成職缺、測試資料與假的 AI 回應，不代表已驗證即時 SEEK 可用性或真實模型品質。

Windows 可使用以下指令核對下載的 ZIP，與 `.sha256` 文字檔中的值比較：

```powershell
Get-FileHash .\seek-auto-v0.2.0.zip -Algorithm SHA256
```

在 Linux 中，把 ZIP 與 `.sha256` 放在相同目錄後執行：

```sh
sha256sum --check seek-auto-v0.2.0.zip.sha256
```

## 已知限制

- SEEK 匯入與搜尋使用非官方端點，可能受網站更新、拒絕存取或限流影響；失敗時可手動貼上描述。
- 這是單人本機應用程式，監聽 `127.0.0.1`，沒有多帳號、雲端同步或公開託管功能。
- AI 請求會把所選職缺、你提供的背景及相關範例送到設定的供應商；API 費用由該服務計算。
- 不包含 Anthropic 原生 Messages API 轉接；自訂服務需符合現有相容介面。
- 適合度分數是參考建議，不代表錄取機率；投遞由使用者在 SEEK 或雇主網站完成。
